    OllamaProvider¶

    wordbase.providers.ollama_provider ¶

    Ollama provider for locally served open-weight models.

    This module implements the APIProvider interface for an Ollama server (https://ollama.com), using the official ollama Python client and the /api/chat endpoint. It lets WordBase talk to any model you have pulled locally (ollama pull llama3.2) -- or to a remote Ollama host -- with no API key.

    The provider handles
    • Connecting to the default local server, OLLAMA_HOST, or an explicit host
    • Message format conversion, including base64 images and tool results
    • Per-token log probabilities (and top-k alternatives)
    • Thinking content, from Ollama's native thinking field or inline ... blocks
    • Tool calling
    • Concurrent n > 1 generation via ThreadPoolExecutor, with per-call derived seeds

    Typical usage example:

    from wordbase.providers.ollama_provider import OllamaProvider
from wordbase.types import Message

provider = OllamaProvider(model="llama3.2")
messages = [Message(role="user", content="Hello!")]
completions = provider.generate(messages, seed=None, temperature=0.7)
print(completions[0]["text"])

    OllamaProvider ¶

    OllamaProvider(model: str, host: str | None = None, timeout: float | None = None, exact_token_counts: bool = False)

    Bases: APIProvider

    Provider for models served by Ollama.

    Inherits generate() and generate_batch() from APIProvider. Ollama has no native n parameter, so n > 1 requests are handled by n concurrent API calls.

    Capabilities and limits
    • Seeds are forwarded natively. For n > 1, call i is seeded with _derive_seed(seed, i) so the batch is reproducible but the completions differ.
    • Token log-probabilities (and top_logprobs) require an Ollama server and model that support them; when requested but missing, a UserWarning is emitted and tokens is left empty. Ollama does not report token ids, so token_id is always 0.
    • Tool calling is supported (supports_tools = True). The Ollama client drops call ids, so ToolCall.id is synthesized as the tool's name (two calls to the same tool in one turn share an id). The server cannot force a tool call, so tool_choice="required" or a specific tool name only warns; tool_choice="none" works by not offering the tools.
    • top_k is not forwarded (APIProvider.generate() does not pass it to providers).
    • Ollama has no tokenize endpoint, so count_tokens() raises NotImplementedError unless exact_token_counts=True. In that mode it asks the server for the prompt token count of a raw one-token generation: exact, but one network round-trip (and a model load) per call. The count may include a beginning-of-sequence token if the model's tokenizer adds one.
    • With exact_token_counts=True, completions that contain thinking also report metadata["thinking_tokens"]: the server's token count of the thinking text (eval_count lumps thinking and answer together). It re-tokenizes the decoded text, so it can differ slightly from the tokens actually generated, and costs one extra request per completion with thinking.
    • Per-request token usage is always in metadata["input_tokens"]/["output_tokens"].

    def __init__(
    self,
    model: str,
    host: str | None = None,
    timeout: float | None = None,
    exact_token_counts: bool = False,
) -> None:
    """Initialize the Ollama provider.

    Construction does not contact the server; connection problems
    surface on the first ``generate()`` call.

    Args:
        model: Ollama model tag. The model must already be pulled on the
            server (``ollama pull <model>``).
        host: Server URL, e.g. "http://gpu-box:11434". When None, the
            client uses the ``OLLAMA_HOST`` environment variable or
            ``http://localhost:11434``.
        timeout: Per-request timeout in seconds, or None for no timeout.
            Large models can take a while to load on first use.
        exact_token_counts: Enable ``count_tokens()`` and
            ``metadata["thinking_tokens"]`` by asking the server to
            tokenize text. Off by default because each count is an extra
            server request.

    Raises:
        ImportError: If the ollama package is not installed.
    """
    super().__init__()
    self.model = model
    self.host = host
    self.exact_token_counts = exact_token_counts
    self._client = ollama.Client(host=host, timeout=timeout)

    def count_tokens(self, text: str) -> int:
    """Count the tokens in text using the Ollama server.

    Ollama has no tokenize endpoint, so this sends ``text`` as a raw
    prompt (no chat template) with ``num_predict=1`` and returns the
    server's ``prompt_eval_count``. It needs a reachable server with the
    model available, loads the model if needed, and may include a
    beginning-of-sequence token.

    Args:
        text: Text to count.

    Returns:
        The exact prompt token count; 0 for empty text, without
        contacting the server.

    Raises:
        NotImplementedError: If the provider was created without
            ``exact_token_counts=True``.
        APIError: If the server is unreachable, fails, or omits the
            token count.
        ModelNotFoundError: If the model is not available on the server.
    """
    if not self.exact_token_counts:
        raise NotImplementedError(
            "Ollama has no tokenize endpoint, so OllamaProvider cannot "
            "count tokens locally. Construct it with "
            "exact_token_counts=True to count tokens via the server "
            "(one extra request per call), or read "
            'completion["metadata"]["input_tokens"]/["output_tokens"].'
        )
    if not text:
        return 0
    with self._mapped_errors():
        response = self._client.generate(
            model=self.model,
            prompt=text,
            raw=True,
            options={"num_predict": 1},
        )
    count = response.prompt_eval_count
    if count is None:
        raise APIError(
            "The Ollama server did not return prompt_eval_count, so the "
            "token count is unavailable."
        )
    return int(count)
